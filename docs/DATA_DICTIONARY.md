# Data dictionary and counting units

`catalog.csv` is a portable derivative. Its numeric values retain original CSV
strings; the original tables and original-row JSONL are also available. Each row
binds cohort, source table, row ordinal and original content into `record_id`.
No old ID is changed. `historical_endpoint_id` can be absent in older small data.
For the original small table (which has no per-row status column), normalized
`COMPLETED` means a saved numerical readout row exists; it is not a newly
inferred source-optimizer convergence or ground-state certification flag.

| Field | Meaning |
|---|---|
| cohort | small-exact-singlet, large-85120, or naphthalene-additional; never pool these silently |
| case | Physical condition ID; full metadata and input digests are in cases.json |
| historical_method_id / display_name | Original name / presentation alias; only B4 maps to RAACS |
| replicate | Original seed/replicate label, not a guarantee of independent source optimization |
| context | Original saved-data view; nested subsets are not new acquisition |
| final_shots / pilot_shots | Samples used by the readout / samples paid during construction |
| total_acquired_model_shots | Recorded acquisition total, when present; not inferred from missing metadata |
| QPU_shots | 0 for these model studies |
| R_target | Requested spin-string cap in this study, not every paper's definition of R |
| D_target / D_actual | Requested / obtained Cartesian determinant dimension; actual D need not reach target |
| singlet_dimension | Dimension after exact singlet projection when recorded; unknown is blank |
| readout_status | Final readout status; different from original source-construction status |
| energy_Ha | Physical-H expectation after classical CI; units Hartree |
| error_mHa | Original recorded error; blank when unavailable; historical clipping is not silently corrected |
| Recovery_percent | 100 (E_HF-E_CI)/(E_HF-E_ref); reference quality must be checked |
| cnot_count / cnot_depth / total_depth | Registered logical sampling-circuit resource, usually final-shot-weighted ensemble mean |
| independent_parameters | Independent ansatz parameter count if known; blank is not zero |
| angle_slots_mean | Stored coefficient/angle slots, not certified independent parameter rank |
| CI_CPU_seconds_actual | Per-record actual new CI CPU work when recorded; a cache hit is not a fresh solve |
| spin_rule | Exact selected-space S=0 in small cohort; penalized-root physical-H evaluation in larger cohorts |

## Important distinctions

Endpoint rows repeat the same source at several Shot/R/D settings. Do not sum
their construction costs as if every row created a new source. Model CNOT
applications are shot times circuit CNOT, not the number of independent circuits.
Content-addressed storage deduplication does not remove real repeated executions
from scientific cost ledgers.

Small-cohort LUCJ has one fixed initialized source reused for three readout seeds;
RAACS has three fresh adaptive constructions; SqDRIFT has three fresh ensembles.
They are not three identical kinds of repeated optimization.

Original source status may say `SOURCE_READY_GPU_FINAL_PENDING` even when a later
readout completed. Preserve that original label and use the separate readout
status. H6 2.2-A CCSD nonconvergence causes missing source records, not bad
measured energies. D-unreached endpoints and missing sources are distinct.

Raw count histograms preserve counts but not an unsaved ordered shot stream.
Where downstream nested subsets were generated by shuffling a multiset, retain
the algorithm/seed; do not claim an original QPU time ordering exists.

## Resource provenance

Distinguish preparation vs measurement-equivalent circuit, logical decomposition
vs routed hardware circuit, and shot-weighted mean vs maximum. A sampling
compiler may preserve Z probabilities without preserving the entire state phase.
New naphthalene LUCJ resource-v2 values are not substituted into older cohorts.
