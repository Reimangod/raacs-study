# Scope and non-destructive preservation

## Included

The core presentation study has six small-molecule conditions (LiH 1.5/3.0 Å,
BeH2 1.3/2.5 Å, linear H6 1.4/2.2 Å), the earlier four larger conditions
(naphthalene 20q, N2 32q at 1.2/2.4 Å, Fe2S2 40q), and the separate additional
naphthalene cohort. The same molecule in distinct cohorts is not one run.

All saved endpoint rows and known missing-source records from these cohorts are
included, not just a best result. Construction policies, decisions, raw model
counts, circuits, physical inputs, CI outputs, source snapshots and failure
records are included as far as saved. A broader historical RAACS archive is
indexed separately; exploratory records are not independent confirmation.

`data/archive-manifest.json` and the generated coverage report are authoritative
for what is actually uploaded. No claim of all historical workspace files or all
possible dependencies follows merely from the word "archive".

## Excluded

Virtual environments, installed packages, caches, redundant transport bundles,
private correspondence, credentials and unrelated old CEO-compression or neural
network studies are not research-data payload. Any excluded scientific input
must appear as a gap; it must not be silently treated as available.

## Preservation rule

Original files are read-only. The source inventory records hashes and source
relative paths. A path-normalized catalog is a derivative, not a replacement
freeze. Historical numeric strings, IDs, statuses and missing values are retained
in original tables or raw-row provenance. New names are aliases only.

This packaging work authorizes no source search, extra seeds, sampling, FCI
reference calculation, remote jobs or changes to existing protocols.
